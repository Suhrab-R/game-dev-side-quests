# game-dev-side-quests

Side Quest submissions for CSCI 4160U - Game Development. Each side quest has
its own folder; open that folder to find the assignment, its README (with build
instructions) and everything submitted for it.

| Folder | Side quest | Start here |
|---|---|---|
| [`sq1/mini-jam/`](sq1/mini-jam/) | Mini Game Jam: ARENA + twist (the brief calls it SQ2), tagged `jam-final` | [README](sq1/mini-jam/README.md) · [Postmortem](sq1/mini-jam/POSTMORTEM.md) |

## Mini Game Jam: build and play

Requires [Odin](https://odin-lang.org). From the root of this repo:

```
cd sq1/mini-jam
odin run src
```

Demo video: https://youtu.be/drz0JDxpAU0 (also in the repo as
[`sq1/mini-jam/demo-video.mp4`](sq1/mini-jam/demo-video.mp4)).
